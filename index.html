Setup Guide

01

Install the app

Run the setup .exe and follow the installer. The package includes the desktop app, Electron runtime, icon assets, and the bundled runtime needed by manga extensions. Normal users do not need Node.js, npm, Java, or any additional tooling.

02

Add your first sources

watchAny does not ship pre-installed third-party sources. Open Settings > Sources and choose the tab for the content type you want to add.

03

Manga and manhwa

Under Sources > Manga, paste a Keiyoushi-compatible repository URL, click Validate & add, then install the extensions you want. Only install extensions from repositories you trust.

04

Movies, TV and anime streams

Under Sources > Media, paste any compatible media manifest URL for streams, torrents, catalogs, metadata, or subtitles. If the add-on requires setup, configure it first, then paste the configured manifest URL.

05

Start browsing

Catalog add-ons appear in the Movies catalog dropdown after they are enabled. Stream and torrent add-ons appear on detail pages when a matching title is opened. Use the Search tab to find anime, manga, or movies by name.

06

Optional cloud sync

The app works fully offline and locally. If you want your library and progress to sync across devices, enable account sync in Settings > Account. You can configure a custom sync server if needed.

Features

Anime and movies

Stream or download using torrents, media manifests, and configured sources. Built-in playback with hardware-accelerated video, subtitle support from multiple providers (including ASS/SSA with embedded fonts), resume playback, speed control, and picture-in-picture mode.

Manga and manhwa

Read with a full-featured reader that supports left-to-right, right-to-left, vertical, and webtoon scrolling. Fit modes, zoom, border crop, background color, and per-page rotation. Bookmarks and progress sync across devices.

Separate libraries

Progress is tracked independently per content type. Anime, manga, and movies each have their own library with separate categories, status filters, and sort options. What you watch or read in one section never affects the others.

Third-party sources

Add media add-ons (Stremio-compatible) for catalogs, streams, torrents, and subtitles. Add Keiyoushi-compatible manga repositories for thousands of manga and manhwa sources. All sources are community-maintained and user-added.

Torrent streaming

Stream content directly from torrents without waiting for a full download. Uses WebTorrent with DHT, PEX, and magnet link support for peer-to-peer streaming. Choose your torrent provider or use the built-in search.

Offline downloads

Download episodes, chapters, and movies for offline viewing with a persistent queue that survives restarts. Track download progress per file and manage storage from the dedicated Downloads page.
